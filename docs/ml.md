# ML/LLM-задачи в системе

## Декомпозиция задач и выбор подходов

1. **Safety Router (Определение рисков)**
   - **Подход:** Синхронная классификация. Использовать LLM нельзя из-за жестких ограничений по времени (<500ms) и стоимости инференса на каждый чих.
   - **Baseline (PoC):** RegEx и эвристики (поиск корней слов "суд", "угроз", "прокурат"). 
   - **Целевое решение:** Легковесный бинарный классификатор (Distilled BERT или Логистическая регрессия). Обучается на исторической разметке.

2. **Intent Classifier (Маршрутизация по темам)**
   - **Подход:** Синхронная многоклассовая классификация.
   - **Baseline (PoC):** Словарные правила.
   - **Целевое решение:** Модель уровня `rubert-tiny`, дообученная (fine-tuning) на исторических тикетах поддержки компании.

3. **Retrieval (Поиск релевантного контекста)**
   - **Подход:** Гибридный поиск для извлечения фактов.
   - **Baseline (PoC):** Заглушка `HybridRetriever`.
   - **Целевое решение:** Двухбашенная архитектура: семантический поиск через SentenceTransformers (embeddings) + лексический поиск (BM25 для артикулов и имен собственных) -> Cross-encoder для реранжирования.

4. **Generation (Генерация ответа)**
   - **Подход:** Асинхронная LLM в RAG-пайплайне.
   - **Baseline (PoC):** Прямой промптинг (имитация через `time.sleep`).
   - **Целевое решение:** Использование API (YandexGPT или аналог). LLM **не используется** для тикетов с запросом персональных данных (PII) и высоких рисков.

## Валидация качества и разметка
- **Технические метрики ML:** Precision/Recall для Safety Router (крайне важен высокий Recall для рисков, чтобы ничего не пропустить); NDCG@5 для Retriever; F1-score для Intent Classifier.
- **Низкая уверенность:** Если `confidence score` любой классификации падает ниже заданного порога (например, 0.75), система отказывается от автоматизации и отправляет тикет человеку (human-in-the-loop).
- **Разметка данных:** Для обучения моделей собирается историческая база тикетов. Первичная разметка интентов делается через пайплайн LLM-as-a-judge, после чего сложные случаи и краевые значения верифицируются людьми-асессорами.
