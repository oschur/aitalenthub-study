# Самоанализ и Stop-метрики (Self-Review)

## Уязвимые места текущей архитектуры (PoC)
1. **Хардкод в SafetyRouter и IntentClassifier:**
   - *Проблема:* Использование жестких правил (поиск по корням слов) не масштабируется, не понимает контекст и уязвимо к опечаткам (например, "пракуратура" вместо "прокуратура").
   - *Решение:* Замена заглушек на легковесные ML-модели (Distilled BERT) перед переходом в Production.
2. **Синхронная имитация асинхронности:**
   - *Проблема:* В PoC задержка LLM эмулируется через `time.sleep()`. В реальном Highload это приведет к блокировке потоков и падению сервиса.
   - *Решение:* Внедрение реальных очередей (Message Queue) и асинхронных RAG-воркеров.
3. **Отсутствие настоящего Reranker-а:**
   - *Проблема:* В PoC ретривер возвращает статический контекст. В целевой системе нужен Cross-encoder для точного отбора релевантных кусков документации из Vector DB.

## Stop-метрики (когда систему нельзя катить в бой)
Продукт нельзя выпускать на реальных пользователей, если:
- **Recall у Safety Router падает ниже 98%** (мы пропускаем жалобы в Роскомнадзор или юридические угрозы во внешний API LLM).
- **Latency горячего контура превышает 1 секунду** (мы не успеваем отбивать базовые запросы, и очередь переполняется).
- **Доля галлюцинаций LLM (по оценке LLM-as-a-judge на тесте) > 5%**.
- **CSAT падает более чем на 0.2 пункта** во время A/B теста автоответов.
