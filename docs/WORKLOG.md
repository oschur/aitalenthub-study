# Журнал работы (Worklog)

**Общее затраченное время:** ~4 часа

## Хронология
1. **Анализ ТЗ и проектирование архитектуры (1.5 часа)**
   - Изучение требований (пики до 20k тикетов, SLA 15 минут, лимит бюджета 150₽ на пользователя).
   - Принятие решения о разделении потока на "горячий" (Safety Router) и "холодный" (RAG/LLM) контуры для соблюдения SLA.
2. **Разработка PoC (1.5 часа)**
   - Написание заглушек для ML-моделей (эвристики и mock-ретривер).
   - Реализация оркестратора (`app.py`) и точки входа `main.py` для автоматизированного тестирования.
   - Создание валидационного датасета (`tickets_sample.csv`).
3. **Документирование (1 час)**
   - Описание архитектуры, ML-задач и мониторинга (разделение на 4 файла по требованиям ТЗ).
   - Оформление Mermaid-диаграмм.
   - Описание `README.md` и инструкций по запуску.

## Оценка скоупа (Что сознательно не вошло в PoC)
Согласно требованиям ("Не писать много кода ради объема", "Не строить production-ready систему"):
- Реальная интеграция с брокерами сообщений (Kafka/RabbitMQ). Асинхронность симулируется на уровне архитектурного дизайна.
- Подключение настоящих LLM API (YandexGPT/OpenAI) заменено на mock-ответ для экономии времени и фокуса на проверке бизнес-логики (маршрутизации).
- Развертывание реальной векторной БД (FAISS/Milvus).
