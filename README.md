# MVP автоматизации тикетов поддержки

Минимальный пайплайн для реализации примерно за 3 часа:

1. `app.py` принимает тикет и запускает обработку.
2. `safety.py` скрывает персональные данные и отмечает рискованные запросы.
3. `classifier.py` делит тикеты на типовые и сложные. Сложные или неуверенно классифицированные тикеты уходят оператору.
4. `retriever.py` ищет контекст в базе знаний: BM25 по ключевым словам плюс семантический поиск. Реранкер можно добавить только при наличии времени.
5. `generator.py` формирует ответ по найденным документам. При ошибке LLM возвращается безопасный шаблон и тикет передаётся оператору.
6. `app.py` записывает в лог маршрут, уверенность классификатора, найденные документы и итог обработки.

## Файлы

- `classifier.py` — простой бинарный классификатор «типовой / сложный».
- `retriever.py` — гибридный поиск по базе знаний.
- `generator.py` — вызов LLM и fallback.
- `safety.py` — PII, рискованные категории и проверка ответа.
- `app.py` — конфигурация, структуры данных, сборка компонентов и простое журналирование.

Папки `data/knowledge_base` и `models` предназначены для документов базы знаний и обученного классификатора.
